# Maintain LeanNiche

Read the [repository guide](../AGENTS.md) before editing. Verify changes using
the [Lean and Python checks](deployment.md) and keep new proof statements
attached to their actual source and compiler evidence.

Run `make docs` to generate source-file and line counts in
`outputs/documentation/code_metrics.md`. The count is an inventory of source
text. The maintained documentation index and examples are authored under
`docs/`.

The [historical documentation](archive/README.md) and
[retained output tree](../outputs/README.md) record earlier work. Keep its
evidence distinct from verification of the current revision.
