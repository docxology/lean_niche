# LeanNiche documentation guidance

Use [README.md](README.md) as the documentation index. Keep setup and
verification commands tied to `lean-toolchain`, `lakefile.toml`, the Python
lockfile, and the compiler tests. Describe runnable proof targets and archived
drafts according to their evidence. Preserve the historical snapshots under
`archive/`.

Maintain the methods note under [manuscript/](manuscript/README.md). Generated
inventories and rendered files belong in local output directories.
