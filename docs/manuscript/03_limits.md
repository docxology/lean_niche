# Interpretation and limits

Successful compilation and acceptable axiom dependencies support the
specific declaration inspected. They do not establish that every file in
the repository or its output tree was part of that build. The default
import list and the individual compiler checks determine the verified
scope.

Python analyses and visualizations illustrate computations. Archived
examples and reports preserve their original status. Reproducing a result
requires recording the relevant source and toolchain and running the
corresponding check again.
