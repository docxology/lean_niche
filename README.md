# LeanNiche

LeanNiche combines a Lean 4 library and executable regression checks with
Python utilities for running Lean, collecting proof evidence, and performing
numerical analysis and visualization.

Start at the [documentation index](docs/README.md). The [setup and verification guide](docs/deployment.md)
runs the pinned Lean compiler and Python checks. The
[exact model guide](docs/exact-models.md) explains the boundary between
rational theorems and Float computations.

The [software methods note](docs/manuscript/README.md) describes the evidence
workflow. The [reported and generated examples](outputs/README.md) retain
their original evidence status.
