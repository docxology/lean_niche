# src/lean/LeanNiche/ — Consolidated Module Namespace

The `LeanNiche` library namespace: consolidated, importable versions of all
domain modules (Basic, Advanced, Statistics, LinearAlgebra, DynamicalSystems,
Lyapunov, ControlTheory, Computational, SetTheory, Tactics, Visualization,
Setup, ProofExport, and more), plus `LeanNicheMain.lean` (main entry for the
library test executable) and `generated_artifacts/` (proof artifacts produced
by example runs).

This directory is the import target for examples; `lake build` compiles it.
